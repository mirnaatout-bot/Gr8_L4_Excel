Working With Data in Excel

Lesson 4 · Spreadsheets and Charts. See how the same steps you learned in class are done in Excel, then try them on a live sheet.

Big question

How does data handling affect AI decisions?

An AI learns patterns from clean, well-structured data. Errors or missing rows can lead to wrong or unfair predictions, so people must prepare and check the data.

The four skills, and how to do them in Excel

1 · Structure

Features and target

Features = inputsTarget = what AI predicts

  1. Put one example per row.
  2. Give every column a clear header in row 1.
  3. Decide which columns are inputs and which one is the target.
2 · Sort and filter

Find what matters

  1. Click inside the table.
  2. Data → Sort → choose VehicleCount, Largest to Smallest.
  3. Data → Filter, then open the arrow on Location and tick SchoolZone.
3 · Summaries

Formulas as evidence

  1. Click an empty cell and type =.
  2. Use AVERAGEIFS to average rows that match, and COUNTIF to count them.
  3. Press Enter, then check the number against the rows.
4 · Charts

See the pattern

  1. Select the labels and the values.
  2. Insert → Column Chart.
  3. Add a title, then say what pattern you see and what an AI might predict.
